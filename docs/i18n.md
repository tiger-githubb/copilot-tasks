# Internationalization (i18n) Documentation

## Overview

The Copilot Tasks VS Code extension supports internationalization using the official `vscode-nls` library. This allows the extension to automatically detect the user's VS Code language preference and display the dashboard in the appropriate language.

## Supported Languages

- **English** (default): `bundle.l10n.json`
- **French**: `bundle.l10n.fr.json`

## Implementation Details

### Language Detection

The extension automatically detects the user's language preference from VS Code settings using `vscode-nls`. No manual configuration is required.

### Fallback Behavior

- If a translation is missing for a specific string, the English default is used
- If the user's language is not supported, English is used as the fallback

### File Structure

```
src/
├── localization/
│   ├── bundle.l10n.json      # English (default)
│   └── bundle.l10n.fr.json   # French
└── ui/
    └── dashboard-panel.ts     # Uses localized strings
```

## Adding New Languages

To add a new language (e.g., Spanish):

1. Create `src/localization/bundle.l10n.es.json`
2. Copy the structure from `bundle.l10n.json`
3. Translate all string values to Spanish
4. The extension will automatically detect and use the new language

Example for Spanish (`bundle.l10n.es.json`):
```json
{
  "dashboard.title": "Panel de Tareas Copilot",
  "dashboard.refresh": "Actualizar",
  "stats.total": "Total de Tareas",
  ...
}
```

## String Key Convention

String keys follow a hierarchical pattern:
- `dashboard.*`: Main dashboard interface
- `stats.*`: Statistics section
- `addTask.*`: Add task form
- `tasks.*`: Task list and management
- `filter.*`: Filter buttons

## Usage in Code

```typescript
import * as nls from "vscode-nls";

const localize = nls.loadMessageBundle();

// Simple string
const title = localize("dashboard.title", "Copilot Tasks Dashboard");

// String with parameters
const message = localize("tasks.added", "Task added: {0}", taskText);
```

## Testing

The i18n functionality is tested in `tests/dashboard-i18n.test.ts` to ensure:
- vscode-nls initializes correctly
- Fallback behavior works as expected
- Parameter substitution functions properly

## Benefits

- **Automatic**: No user configuration required
- **Extensible**: Easy to add new languages
- **Standards-compliant**: Uses VS Code's recommended i18n approach
- **Robust**: Graceful fallback to English if translations are missing
